# Benchmarks for xDSL

[![asv](https://github.com/xdslproject/xdsl-bench/actions/workflows/asv.yaml/badge.svg)](https://github.com/xdslproject/xdsl-bench/actions/workflows/asv.yaml)

This repository contains the infrastructure and artefacts from benchmarking the
xDSL compiler framework with air-speed velocity. See
[xdsl/benchmarks](https://github.com/xdslproject/xdsl/tree/main/benchmarks) for
the benchmarking and profiling code.
