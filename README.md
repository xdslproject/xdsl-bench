# Benchmarks for xDSL

This repository contains the infrastructure and artefacts from benchmarkingthe
xDSL compiler framework with air-speed velocity.

See [xdsl/benchmarks](https://github.com/xdslproject/xdsl/tree/main/benchmarks)
for the benchmarking and profiling code.

***This repository is currently under development, so is not stable. Benchmarking infrastructure may fail and not immediately be fixed.***
